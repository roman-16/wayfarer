# Wayfarer

A vanilla+ Minecraft modpack about a nomadic journey, for Minecraft 1.21.1 on NeoForge. Twelve eye shards lie hidden in shrines at the far ends of a vast world. The ember you carry feels them, warmer and colder, until one answers. Gather all twelve, find the true gate, and kill the dragon. Never settle on the way.

The same pack runs in singleplayer and on a dedicated server: every rule ships inside the Wayfarer mod or the pack's configs.

## Setup

You need [devbox](https://www.jetify.com/devbox) and [direnv](https://direnv.net). Everything else comes from `devbox.json`.

```console
$ git clone https://github.com/roman-16/wayfarer.git
$ cd wayfarer
$ direnv allow
```

## Play

```console
$ just pack
```

This writes two files to `dist/`:

| File | Use |
|---|---|
| `Wayfarer-<version>.zip` | In Prism Launcher: **Add Instance → Import**, pick the zip |
| `Wayfarer-<version>-server.zip` | Unpack on the server and run `run.sh --nogui` (or `run.bat`). The pack sets `difficulty=hard` |

To look at the pack without installing it anywhere:

```console
$ just client
```

This opens a creative dev client in the **showroom**: a flat world with all twelve shrines in a row (the signs name them), the Last Camp at spawn and a wall of every Wayfarer item. The showroom is rebuilt on every launch, so it always shows the current generator output. A natural world with a fixed seed sits beside it and is kept between launches: `/execute in minecraft:overworld run tp @s 0 200 0` goes there, `just client fresh` starts it anew.

To play on this machine's own dedicated server:

```console
$ just server
```

Running a server means you accept the [Minecraft EULA](https://aka.ms/MinecraftEULA): `just server` and `just test` write `eula=true` for you.

## Tasks

| Task | Does |
|---|---|
| `just build` | Builds the Wayfarer mod |
| `just clean` | Removes everything generated by builds and runs |
| `just client` | Opens the pack in a creative dev client, in the showroom |
| `just generate` | Regenerates the shrines, structure sets, templates, removals, textures and the quest book |
| `just lint` | Fixes and formats everything, then checks the pack's rules |
| `just pack` | Exports the client zip and the server pack |
| `just server` | Runs the pack's dedicated server locally |
| `just survey` | Measures how far each shrine lies from many points in five fixed worlds, against the trip targets in `balance.toml`; `just survey apply` writes tuned spacings |
| `just test` | Runs the mod's game tests, then boots the whole pack headless and checks the world |
| `just update` | Moves every mod and tool to its newest version, then lints and tests |

## Layout

| Path | Holds |
|---|---|
| `balance.toml` | Every balancing number: compass, gaze, unlocks, shrine and stronghold distances, structure spread |
| `generator/` | The shrine generator, the twelve eyes (`eyes.toml`), the recipe and structure removals, the Nether audit list |
| `mod/` | The Wayfarer mod (NeoForge, Java 21); `src/dev` holds the game tests and the dev client's driver, which never ship |
| `pack/` | The packwiz pack: one file per mod, and the pack's configs |
| `scripts/` | The server pack builder, the boot test, the Nether audit and the rule checks |
| `story/` | The lore everything else is written from, and the quest book (`quests.toml`) |
