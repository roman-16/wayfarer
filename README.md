# Wayfarer

Wayfarer 1: every 1.x version loads into a road begun on 1.x, and the Prism instance fetches each one by itself before it starts.

A Minecraft modpack about a nomadic journey, for Minecraft 1.21.1 on NeoForge, for one to four players. You wake at a dying stranger's fire with no name, and he gives you his ember. It leads to twelve hidden halls across a vast, sparse world, where the shards of the dragon's broken Eye each met their own fate. A caravan of survivors follows your marks, and each day you walk from its fire into the road's people, scenes and nights. Every choice comes back.

The same pack runs in singleplayer and on a dedicated server: every rule ships inside the Wayfarer mod or the pack's configs.

## Setup

You need [git](https://git-scm.com), [devbox](https://www.jetify.com/devbox) and [direnv](https://direnv.net). Everything else comes from `devbox.json`.

```console
$ git clone https://github.com/roman-16/wayfarer.git
$ cd wayfarer
$ direnv allow
```

Keys for outside services live in `.env`, which devbox loads. `.env.example` names every key: copy it to `.env` and fill in the ones you need.

## Play

In Prism Launcher: **Add Instance → Import**, and give it the address of the major version's instance:

```text
https://roman-16.github.io/wayfarer/1/Wayfarer.zip
```

Before every launch the instance fetches what changed in the newest 1.x version. Offline, packwiz's window offers to continue without updating.

To build and publish a version:

```console
$ just pack      # dist/: the Prism instance, the pack it hosts, the Wayfarer jar and the server pack
$ just publish   # the GitHub release of the version in pack/pack.toml, which GitHub Pages serves
```

| File in `dist/` | Use |
|---|---|
| `Wayfarer-<major>.zip` | The Prism instance that updates itself from the hosted address |
| `Wayfarer-<version>-pack.zip` | The pack the address hosts |
| `wayfarer-<version>.jar` | The Wayfarer mod, which the hosted pack downloads from the release |
| `Wayfarer-<version>-server.zip` | Unpack on the server and run `run.sh --nogui` (or `run.bat`). The pack sets `difficulty=normal` |

To look at the pack without installing it anywhere:

```console
$ just showroom
```

This opens a creative dev client in the **showroom**: a flat world with all twelve halls in a row (the signs name them), the Last Camp at spawn with the stranger's two old camps beside it and a wall of every Wayfarer item. The showroom is rebuilt on every launch, so it always shows the current generator output. The compass runs there as a demo, pointing at a waymark 750 blocks west of the camp, with a companion circling the camp and the camp's grave marked, so walking to the waymark and back shows every reading. A natural world with a fixed seed sits beside it and is kept between launches: `/execute in minecraft:overworld run tp @s 0 200 0` goes there.

To play the pack the way a player meets it, on a fresh world in survival:

```console
$ just play
```

Both dev clients run without shaders, without Distant Horizons and at 8 chunks, so they start and run fast; the exported pack keeps all three. `just showroom lean` and `just play lean` load only the Wayfarer mod and the few mods it needs, in worlds of their own, for work on the mod itself.

To play on this machine's own dedicated server:

```console
$ just server
```

Running a server means you accept the [Minecraft EULA](https://aka.ms/MinecraftEULA): `just server`, `just test` and `scripts/server.py` write `eula=true` for you.

## Tasks

| Task | Does |
|---|---|
| `just boot` | Audits the server pack's jars, boots it headless and checks the world |
| `just build` | Builds the Wayfarer mod |
| `just carry` | Carries the exaroton server's road into a fresh world: the story at the team's step with their own answers, and every player's things; `just carry <server> <quest/step>` carries it back to an earlier step of the main quest under way, `just carry <server> upload` puts it on the server and switches to it, and `just carry <server> pack` puts the server pack from `just pack` on the server, uploading only what changed |
| `just clean` | Removes everything generated by builds and runs |
| `just compile` | Compiles the Wayfarer mod and its dev code |
| `just devserver` | Runs the dev server in the foreground, with the Wayfarer mod's dev code; `just devserver lean` with only the Wayfarer mod |
| `just exaroton` | Records the exaroton server's console, status and players, memory, tick time, log, world sizes and the region files that vanish or shrink into `exaroton/` until you stop it, naming first the world the server opens |
| `just gametest` | Runs the mod's game tests headless |
| `just generate` | Regenerates the halls, structure sets, templates, removals, textures and the quest book |
| `just lint` | Fixes and formats everything, then checks the pack's rules |
| `just pack` | Exports the client zip and the server pack, whose Wayfarer jar leaves out the sounds and textures only a client plays or draws |
| `just play` | Opens the pack in a dev client on a fresh natural world, in survival; `just play lean` with only the Wayfarer mod |
| `just registries` | Writes every registry, tag and recipe of the running pack, from every mod, into `build/reports/` |
| `just server` | Runs the pack's dedicated server locally |
| `just showroom` | Opens the pack in a creative dev client, in the showroom, with the compass demo; `just showroom lean` with only the Wayfarer mod |
| `just sources` | Unpacks Minecraft's and NeoForge's code and every mod, decompiled, into `build/sources/` for searching |
| `just test` | Runs `just gametest` beside `just boot`, and fails when either fails |
| `just update` | Moves every mod and tool to its newest version, then lints and tests |
| `just voice` | Designs, keeps and saves the story's voices with ElevenLabs from `story/voices.toml`, records every silent line and checks each take (`just voice record`), and shows what is left to record |

## Layout

| Path | Holds |
|---|---|
| `balance.toml` | Every balancing number: compass, daylight, difficulty, fire, gate, gaze, the graphics presets, hunger, leads, nights, sight, stillness, unlocks, each place's distance ahead, the world's shape and the ring of frames, structure spread |
| `design/` | What the pack is becoming, decided before it is built (`README.md` names the phase and what comes next), the lore everything else is written from (`lore.md`) and the narration cast (`narration.md`) |
| `generator/` | The structure generator (the twelve halls, their surface covers, the Last Camp and the stranger's old camps), the twelve eyes and their peoples' places (`eyes.toml`), the recipe and structure removals, the Nether audit list and the features accepted as natural |
| `mod/` | The Wayfarer mod (NeoForge, Java 21); `src/dev` holds the game tests and the dev client's driver, which never ship |
| `nix/` | The ElevenLabs CLI's static release build, pinned for devbox (`elevenlabs-cli/`) |
| `pack/` | The packwiz pack: one file per mod, and the pack's configs |
| `scripts/` | The server pack builder, the boot test, the Nether, portal, load order, structure removal and feature audit, the rule checks, the dev client driver with its screenshot tour, the dev server driver and the library both drivers share, the sources unpacker, the exaroton recorder and the carry to a fresh world |
| `story/` | The quests, memories and Years later (`quests.toml`), the people (`people.toml`), the books (`books.toml`), the road's scenes (`scenes.toml`), the caravan's camp (`caravan.toml`), the gear (`gear.toml`), the dice (`dice.toml`), the music and sounds (`sounds.toml`), the states' seed (`states.toml`), and the voices, who reads what (`voices.toml`) with each kept design and every clip's record (`voices/`) |
